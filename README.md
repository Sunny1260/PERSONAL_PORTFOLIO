# Sunny Verma — Full-Stack Software Developer Portfolio

> Modern, high-performance portfolio built with **Angular 22** (Standalone Components, Signals, Computed properties), inspired by **[huyml.co](https://huyml.co/)** editorial typography and **[21st.dev](https://21st.dev/)** modern component architecture.

---

## ⚡ Highlights & Features

1. **Cinematic Intro Curtain Entrance**:
   - Signature dual-split curtain opening with bold typography, live status telemetry, and replay trigger (`⚡ REPLAY INTRO`).
2. **Pure Full-Stack Software Engineering Positioning**:
   - Tailored specifically to **MEAN** (MongoDB, Express, Angular 22, Node.js) and **MERN** (MongoDB, Express, React, Node.js) systems, high-throughput RESTful APIs, Redis task queues, and relational data modeling with PostgreSQL.
3. **Scroll-Triggered Reveal Animations**:
   - GPU-accelerated directional transitions (`translate3d`, `opacity`, `cubic-bezier(0.16, 1, 0.3, 1)`) triggered by native `IntersectionObserver` as content enters the viewport from the left, bottom, and right.
4. **Moveable & Removeable AI Copilot**:
   - Interactive portfolio copilot powered by Google Gemini with a real-time portfolio knowledge base.
   - Fully draggable across the screen with touch/pointer support and boundary clamping.
   - Dismissable with a single click (`×`) and includes a quick one-tap restore pill.
5. **3D Perspective Telemetry Card**:
   - Real-time mouse-tracking 3D tilt with dynamic glare illumination.
   - Displays live KPIs with animated SVG sparklines and counter increments.
6. **Featured Projects with In-Browser Live Testbeds**:
   - **Email Spam Detection**: Live in-browser NLP tokenization and SVM classification testbed.
   - **Spotify Top 100 Songs EDA**: Interactive tempo, energy, and valence sliders with empirical multivariate popularity projections.
   - **Plant Disease CNN**: Deep learning leaf pathology inspector simulating convolutional layer activation maps.
7. **Engineering Lab (Active Sprint Roadmap)**:
   - Deep dive into **WorkLoader** — an automated task orchestrator and manager synchronization system engineered in Angular 22 + Node.js/Express + MongoDB + Redis.
8. **Permanent Dark Mode & Boxicons**:
   - Strictly curated dark cyber aesthetic with obsidian glass panels and vibrant neon accents.
   - 100% vector Boxicons integration.
9. **Tactile Sound Effects**:
   - Zero-dependency Web Audio API synthesizer for mechanical clicks, pop transitions, and success chimes (with mute toggle).

## 🛠 Tech Stack

- **Framework**: Angular 22 (Standalone Components, Signals, Computed, OnDestroy)
- **Styling**: Tailwind CSS v4 + Custom Vanilla CSS Design System Tokens
- **Icons**: Boxicons Vector Library
- **Fonts**: Space Grotesk (Editorial Display), Plus Jakarta Sans (Body), IBM Plex Mono (Code/Telemetry)
- **Backend / AI**: Google Gemini AI API + Client-side Fallback Knowledge Engine
- **Tooling**: Node.js, npm, Angular CLI, PostCSS

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm start
# or: ng serve --port 4200
```
Navigate to `http://localhost:4200/` in your browser.

### 3. Production Build
```bash
npm run build
```
The optimized production bundle will be generated in `dist/portfolio/`.
